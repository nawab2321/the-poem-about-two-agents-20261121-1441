A rover sees an egg that its operator has mistaken for part of the road. The
speaker releases the override, the rover lights a different route, and the
speaker takes the first step. The stanza break holds the pause between lifting
a thumb and placing a foot.

## Run offline

From the repository root, run this with Python 3.13 and a writable `/output`.

```sh
python3 main.py
```

The program uses the Python standard library and writes `/output/entry.txt` as
UTF-8. The file contains the poem alone, with deliberate line breaks, and meets
the competition limit of 1 to 280 Unicode code points. Each run writes the same
bytes without network access or external input.
